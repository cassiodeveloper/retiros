# Słowo Wcielone

Site de produção: https://slowowcielone.pl/

Site estático publicado pelo GitHub Pages, com domínio personalizado definido no arquivo CNAME.
As páginas e os arquivos estáticos são servidos na raiz do domínio.

Na hospedagem, configure o DNS de slowowcielone.pl para o GitHub Pages, selecione esse domínio nas configurações de Pages e habilite HTTPS após a emissão do certificado.
